# SPTA Website Demonstration

A multi-page, responsive website demonstration for the Seshego Polokwane Taxi Association (SPTA).

## Project status

- Research and initial content inventory: in progress
- Design blueprint: initial draft
- Static HTML/CSS/JavaScript implementation: pending
- Client content verification: pending

## Proposed pages

1. Home
2. About SPTA
3. Routes and commuter information
4. News and announcements
5. Business directory
6. Gallery
7. Contact

## Technology

The demonstration uses plain HTML, CSS and vanilla JavaScript. No framework, backend, database or build step is required.

## Running locally

Open `index.html` in a modern browser. If browser restrictions affect local assets or navigation, run a local static server, for example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Content integrity

Only researched or client-supplied facts should be presented as facts. Proposed marketing copy must not imply unverified services, leadership, history, route coverage, achievements or advertising arrangements. Demonstration business listings must be clearly labelled as examples until real advertisers are supplied.

## Client assets

The client supplied 12 JPEG photographs in `Spta-images.zip`. They are being inventoried for use in the website's local `assets/images/` directory. The supplied SPTA logo should be retained as the organisation's identity asset.
